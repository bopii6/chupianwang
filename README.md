# 出片王（原型）

给教培机构和个人用的竖屏视频自助出片工具。客户选一个「形式」，写一句话，AI 写文案、自动配音，**在客户自己电脑的浏览器里渲染出 MP4**。

## 运行

```bash
npm install
```

```bash
node server.js
```

然后用电脑上的 Chrome 或 Edge 打开 http://localhost:5173

- 配音：开发期用 `edge-tts`（需要 `pip install edge-tts`）。**商用前要换成微软 Azure 语音服务**。
- AI 文案：把 `.env.example` 复制成 `.env`，填入 `DEEPSEEK_API_KEY=...`。不填也能用「先看示例」体验。

## 桌面软件（安装包，给客户用的正式方式）

客户只要双击 `chupianwang-setup-版本号.exe`，不用装 Node、Python、Git，装完桌面上有「出片王」图标。

- 第一次打开如果没填 AI 密钥会弹出填写框（存在客户电脑的数据目录，安装包里不带密钥）
- 客户数据在 `%APPDATA%\出片王`（作品、文案库、登录数据、`.env`、`server.log`），卸载重装、升级都不丢
- 老客户（以前用 bat 脚本的）第一次打开会自动把原项目文件夹里的作品、文案、密钥**复制**过来，老文件夹不动
- 自带 Chrome 内核，不存在“浏览器太旧导不出视频”的问题；自带精简版 Python（24MB）只用来配音
- 没签名：第一次运行会弹“Windows 已保护你的电脑”，点「更多信息 → 仍要运行」

打包（在开发电脑上）：

```bash
npm run dist
```

产物在 `dist/`。`npm run dist` 会先跑 `scripts/build-python.mjs` 重做精简版 Python。微软改了配音接口导致没声音时：改 `scripts/build-python.mjs` 里的 `EDGE_TTS` 版本号，重新打包发布。

开发时直接以桌面软件方式运行：`npm run app`。自检（打包后验证）：设环境变量 `CPW_SELFTEST=<输出文件夹>` 启动，会截图并检查导出能力、配音、听写模型、字体；再加 `CPW_SELFTEST_EXPORT=1` 会真的导出一条示例视频。结果写到 `selftest.json` 后自动退出。`npm run release` 发布前会自动跑这一整套。

## 后台出片（默认无窗口，不弹浏览器）

服务带一个出片 worker：开着它，别的东西（Agent、脚本、MCP 客户端）就能直接下单出片，不用人点页面。

- **默认无头**：worker 启动的 Chrome 带 `--headless=new`，**桌面上不会弹窗口**，安静跑完。
- **想看过程**：启动前设 `JOB_HEADLESS=0`，就会弹出浏览器窗口，能看着它自己选形式、填主题、点导出。调试和演示用。
- **必须带 `JOB_WORKER=1`**：`打开出片王.bat` 走 `scripts/open.mjs`，已经自动带上了；手工 `node server.js` 起的话 worker 是关的，`create_video` 会返回「未开启渲染 worker」。
- **实测耗时**（1 分钟片子）：无头约 **30 秒**，有窗口约 **90 秒**。无头反而快一倍多，因为不用合成窗口。

对外接口是 MCP：`POST http://127.0.0.1:5173/mcp`，工具 `list_formats` / `create_video` / `remix_video` / `list_works` / `prepare_video`。
返回的是**本机绝对路径 + 标题、时长、大小**，不含任何链接（本机地址在外面打不开，给了会误导）。接入写法见 `docs/MCP-接入.md`。

桌面软件版暂时没有开出片 worker（MCP 只能在脚本版上用）。

## 装到客户电脑上（老办法：脚本版，逐步淘汰）

1. 客户电脑装好 [Node.js 20+](https://nodejs.org/zh-cn)、[Python 3.10+](https://www.python.org/downloads/)（安装时勾 “Add python.exe to PATH”）、Git、Chrome 或 Edge
2. 拉代码：`git clone https://github.com/bopii6/chupianwang.git`（私有仓库，要用有权限的账号或令牌）
3. 进项目目录运行 `node scripts/setup.mjs`：装依赖、装配音、下载听写模型（走国内镜像），创建 `.env`，并在 `~/.claude/CLAUDE.md` 写好口令
4. 在 `.env` 里填 `DEEPSEEK_API_KEY`
5. 以后：双击 `打开出片王.bat`，或对 Claude 说“打开出片王”（后台启动 + 打开浏览器，日志在 `server.log`）
   - 更新：双击 `更新出片王.bat`，或说“更新出片王”。更新前记下当前版本，新版启动不起来会自动退回；更新完会列出这次改了什么
   - 退回上一版：`node scripts/update.mjs --rollback`
   - 关闭：`node scripts/open.mjs --stop`
6. 客户报问题：让他点页面右下角的「出片王 v…」→「复制诊断信息」，发微信给我们（含版本、浏览器、配音/模型状态、页面报错、日志最后 60 行；不含文案、视频、密钥、邮箱）

改名说明：以前叫“微信出片”。`打开微信出片.bat`、`更新微信出片.bat` 先留着，给还没更新过的老客户用；等所有客户都更新过一次再删。

安全：服务默认只监听本机 `127.0.0.1`，同一 WiFi 的其他设备连不上；只认 `localhost` 地址，其他网站发来的修改请求一律拒绝。要局域网访问（比如手机扫码上传）在 `.env` 里设 `HOST=0.0.0.0`。

## 时长和等待时间（实测，给客户的说法）

时长按钮写的是范围，不是精确值（AI 按字数写，做不到正好几分钟）：

| 按钮 | 实测成片 | 说明 |
|---|---|---|
| 1 分钟内 | 40–70 秒 | |
| 1–2 分钟 | 75–130 秒 | 手绘图解标“1 分钟出头” |
| 2–3 分钟 | 130–175 秒 | 手绘图解每句 ≤16 字，最长约 1 分半，标“1 分半左右” |

字数明显不够（不到目标的 75%）时，服务端会让 AI 补写一次，日志里有 `[篇幅]` 一行。

等待时间：写文案 10–30 秒，配音 10 秒左右，导出 MP4 大约和视频一样长（1 分半的视频约 1 分半）。

## 作品墙（直播时放）

打开 http://localhost:5173/works.html，顶栏「作品墙」也能进。

- 成片存在项目下的 `works/` 目录（`.gitignore` 里的 `*.mp4` 已经忽略它，不会进仓库）
- 每次点「生成视频」导出后，会自动多存一份到这里，导出完成页有「去作品墙」按钮
- **以前导出的视频不会自己回来**：把 MP4 直接拖到作品墙页面上，或点「导入视频」多选导入
- 「直播模式」是整屏轮播，一条播完自动切下一条；`←` `→` 手动切，空格暂停，`Esc` 退出
- 视频从 `/works/<文件名>` 提供，支持 Range，能拖进度条
- 单条可删除（删的是 `works/` 里的文件，不可恢复）

## 新增一种形式

1. 在 `形式库/` 写说明书（拆对标样片）
2. 写 `prompts/<id>.md`（AI 怎么按这个结构写文案）
3. 写 `public/forms/<id>.js`，导出 `meta`、`skins`、`plan()`、`drawFrame()`、`preloadFonts()`
4. 在 `registry.js` 里登记，并放一份示例到 `public/samples/`

## 爆款变原创（首页“别人的爆款文案 + 你的行业 + 获客模板 = 你的原创视频”）

对客户的说法是一个等式：别人的爆款文案 + 你的行业 + 获客模板 = 你的原创视频（画面用出片王的模板）。界面上不用“复刻”这个词，免得客户以为连画面都照搬；要和原视频一样的画面走 899 定制。

流程：客户上传视频 → **浏览器里**拆出音轨、转成文字（视频不上传）→ `/api/remix-plan` 拆出“为什么火 + 打法 + 推荐模板” → 客户填“做什么培训的” → `/api/script` 带上原文稿照打法重写 → 正常出片。

- **转文字全在客户电脑上跑**：transformers.js + Whisper base 量化版（约 77MB，第一次使用时下载，浏览器会缓存）。2 分钟视频大约 50 秒（16 核电脑实测 112 秒视频 52 秒；核数少的电脑会慢一些）。有少量同音错字，AI 改写时按上下文理解。
- **模型文件**放在 `.cache/models/web/onnx-community/whisper-base/`，换电脑要重新下载（huggingface.co 的 `onnx-community/whisper-base`：10 个配置文件 + `onnx/encoder_model_quantized.onnx` + `onnx/decoder_model_merged_quantized.onnx`）。同目录下还有更准但慢 2.5 倍的 `whisper-small`（250MB），在 `.env` 里写 `ASR_MODEL=whisper-small` 可切换。
- **正式上线**：77MB 模型最好放到对象存储/CDN，在 `.env` 写 `ASR_MODEL_BASE=https://你的CDN/asr/`（目录结构同上，CDN 要允许跨域），不占服务器带宽。
- 页面开启了跨源隔离（`Cross-Origin-Embedder-Policy: credentialless`），转文字才能用多线程；外站图片（Pexels）不受影响。
- MP4/MOV 用 mp4box + WebCodecs 解出音轨（2 分钟视频约 1 秒）；其它格式退回浏览器自带解码。
- 重写后服务端自动检查：和原文连续 8 个字相同（照抄）或命中 `文案库/违禁词.json` 里“违法”级的说法，会带着问题让 AI 重写一次。
- **手机扫码上传**（首页入口已关掉，没测完；服务端代码还在）：电脑上出二维码 → 手机打开 `/m/up.html` 选视频 → **在手机上**拆出声音，只上传 16kHz 声音（约 2MB/分钟，不传视频）→ 服务端 `lib/relay.js` 暂存，电脑取走后立刻删除，二维码 30 分钟有效。本机开发时二维码里自动换成电脑的局域网地址，手机要连同一个 Wi-Fi；Windows 第一次可能弹防火墙提示，要允许 node 访问网络。
- 手机端在 HTTPS 下用快速解码（约 1 秒）；本机开发走 http 局域网地址时浏览器不给用，会退回慢的解码（2 分钟视频约 20 秒），正式上线有 HTTPS 就没这个问题。

## 登录（邮箱验证码）

**现在是关着的（测试阶段）**：不用登录就能生成。要打开时在 `.env` 里加一行 `AUTH_REQUIRED=1`，重启服务即可。

打开后：随便看、点灵感、选模板都不用登录；点“生成”或上传别人的爆款视频时才弹出登录框，登录完自动接着做。新用户 3 条免费试做：每成功生成一条扣 1 条（失败不扣），用完后 `/api/script` 返回 402，页面提示开通；账号菜单里显示还剩几条。用户文件里 `plan` 改成别的值（如 `lifetime`）就不限条数。

- 服务端 `lib/auth.js`：发 6 位验证码（10 分钟有效，同一邮箱 60 秒发一次，一个码最多试 5 次，同一 IP 每小时最多 20 次），登录状态是签名 cookie，30 天有效。没登录时 `/api/script`、`/api/remix-plan` 返回 401。
- 用户数据在 `data/users/<id>.json`（邮箱、注册时间、试用次数）。签名密钥优先用 `.env` 的 `SESSION_SECRET`，没有就自动生成 `data/.session-secret`。**`data/` 要备份，不要上传到公开仓库。**
- **发信邮箱**（在 `.env` 里配）：
  ```
  SMTP_HOST=smtp.qq.com
  SMTP_PORT=465
  SMTP_USER=你的邮箱@qq.com
  SMTP_PASS=邮箱的 SMTP 授权码（不是登录密码）
  MAIL_FROM=出片王 <你的邮箱@qq.com>
  ```
  QQ 邮箱、163 邮箱都能免费开 SMTP（个人邮箱每天能发几百封，起步够用）；量大了换阿里云邮件推送。
- **没配发信邮箱时是开发模式**：验证码打印在服务端日志里；本机访问时登录框里直接显示并自动填好，方便自己测试。

## 行业主题和画面种类（让同一个模板做出来不重样）

- **行业主题**（`public/forms/themes.js`，五个模板共用）：AI 从 17 类行业里选一个 key，再给 2-3 个行业表情。17 类依次是 k12、art、music、dance、coding、driving、beauty、fitness、cooking、language、exam、business、legal、health、counsel、vocation、finance（除培训外，法律、大健康、升学咨询、职业技能、财税也能选）。各模板按自己的风格用：真人图文口播换主色、背景表情壁纸、讲师旁的行业徽章；黑金数据卡加行业徽章，背景大字按行业挑（琴、驾、码）；系列开场换霓虹渐变色和屏幕里的表情壁纸；深度解读换标签颜色、顶栏行业图标，实拍图按行业搜；像素小剧场换强调色，并有行业场景（练习室、电脑教室、练车场）和行业道具（钢琴、教练车、电脑、画架、哑铃、蛋糕、话筒、指甲油、路锥）。加行业时 `themes.js` 和 `prompts/*.md` 里的品类清单要一起改。
- **画面种类**：手绘图解 26 种场景；真人图文口播 24 种；黑金数据卡 28 种模块；系列开场 30 种；深度解读 28 种贴片；像素小剧场 10 个场景、23 种道具。AI 按“这一段在讲什么”挑。
- **每条随机安排**：服务端（`server.js` 的 `LAYOUT_POOLS`）每次随机定开场画面和几种主打画面，附在给 AI 的话后面，同一句话做两次也不一样。
- **合规检查**：每条生成都过一遍 `文案库/违禁词.json` 里“违法”级的说法，有就让 AI 改写一次。
- **防 AI 编内容**（`server.js` 的 `FAB_RULES`）：查占位词（XX驾校、某某老师）和客户没给过的人数、比例、价格、适合年龄、教龄、服务承诺（免费试听、名额、一对一…）、头衔（金牌、名师…）。客户输入和资料里出现过的不算。查到就和违禁词一起让 AI 改一次；改完还剩的，随文案返回 `_flags`，编辑区把那段标黄让客户核对，改掉后自动消失。
- **结尾随机**：每条随机一种互动引导（提问、收藏、关注下期、留关键词、转发、聊踩坑、私信），真人图文口播的结尾画面也随机，不再每条都是“评论区扣 1”。复刻时结尾跟原视频走。
- **配音按行业**：客户没自己挑过声音时，按行业自动配（驾校/健身激情男声，美甲/烘焙/音乐舞蹈美术温暖女声，少儿类活泼女声，深度解读/数据卡播音腔）；挑过一次就一直用他挑的。
- **AI 用量**：每次调用在服务端日志打一行 `[AI 用量]`。系统提示词是固定的（随机安排都放在用户消息里），DeepSeek 会自动缓存这段，重复调用很便宜；不要把随机内容挪进系统提示词。

## 手绘图解（第 6 个模板，`public/forms/sketch-talk.js`）

米白纸底，顶部大字幕逐字出现、关键词（`hl`）变色；中间是粗描边加错位阴影的手绘小道具场景；讲师站在右下角（有形象照用形象照，没有用卡通讲师）。
- 26 种场景：badge 大图标盖章、spotlight 聚光灯、count 记分牌、flash 整屏闪色、phones 两台手机加观众、crowd 观众反应、target 靶子、calendar 翻页日历、stack 叠卡片、gauge 表盘、weeks 周卡、word 深色关键词、grid 矩阵、brand 名片、button 大按钮、checklist 清单、follow 关注、chat 对话、bars 柱状图、versus 对决、timer 秒表、path 路线、quote 便签金句、mystery 盲盒揭晓、progress 进度条、bulb 灯泡。
- `sign` 吊牌只用在“第 N 个点”的段落（num 必须是数字，开头/结尾这类会被过滤）。
- 皮肤：米白纸感、清爽浅蓝、深夜黑板；浅色皮肤的点缀色跟着行业换。
