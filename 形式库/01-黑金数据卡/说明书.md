# 形式 01：黑金数据卡

> 对标样片：`C:\视频剪辑\downloads\huachuang-20261110.mp4`（@宏观棱镜《经济转型的8重K型分化》，4分37秒，1080×1920）

## 一句话灵魂

**一页一个观点，跟着口播把一张信息图一块一块“搭”出来。**

观众不是在看画面，而是在看“论证过程”：标题先抛观点 → 数据/对比一点点出现当证据 → 最后金色一句话下结论。
整条视频只有一个固定画框，变的只有画框里的内容。这让视频显得专业、克制、像研究报告。

## 适合谁

| 客户 | 用来做什么 |
|---|---|
| 教培机构 / 老师 | 讲知识点、讲考试政策、讲升学数据、讲“为什么要学 X” |
| 个人知识博主 | 行业分析、读书拆解、干货清单 |
| 职业培训 / 考证 | 讲行业前景、薪资对比、考试变化 |

关键词：**讲道理、摆数据、有结论**。不适合情绪化、剧情化内容。

## 固定画框（整条视频不变）

```
┌──────────────────────────────┐
│ (头像) @账号名                 │  ← 账号区
│      系列大标题（金色）          │  ← 整条视频的总标题
│ ┌──────────────────────────┐ │
│ │ ▍01 / 小标签               │ │  ← 段落编号
│ │ 标题第一行（白）             │ │  ← 观点（两行，白+金）
│ │ 标题第二行（金）             │ │
│ │ 副标签 · 关键词              │ │
│ │                            │ │
│ │   【可视化模块】             │ │  ← 证据区（6 种模块，见下）
│ │   [标签] [标签] [标签]       │ │
│ │ ─────────────────────────  │ │
│ │ 金色结论句                   │ │  ← 结论
│ └──────────────────────────┘ │
│   (头像) ▌▌▌▌声波▌▌▌▌  ▶      │  ← 仿语音条，跟着配音跳动
│        @账号名                │
│     字幕第一行                 │  ← 口播字幕
│     字幕第二行                 │
└──────────────────────────────┘
背景：深色 + 一个巨大的主题字（样片里是 K），半透明金色，缓慢漂移
```

## 可视化模块（从样片中抽象出 6 种）

| 模块 | 样片中的例子 | 换成教培可以是 |
|---|---|---|
| **对比** compare | 宏观增长↑ ⟷ 个人体感持平 | 死记硬背 ⟷ 理解方法 |
| **数据卡** stats | 161 → 408 万元（数字+进度条） | 平均分 72 → 91 |
| **格子清单** grid | 八重K型分化 8 格 | 中考 4 大必考题型 |
| **流程链** flow | 算力/数据 → 大企业 → 头部城市 | 预习 → 课堂 → 错题本 → 提分 |
| **问题列表** list | 增长在哪？多少人参与？流向谁？ | 家长最该问的 3 个问题 |
| **纯标题** none | 段落开头 / 收尾 | 开场钩子、结尾号召 |

## 节奏规则

- 每段约 10–20 秒，2–5 句口播。
- 段落开始：只出标题第一行 → 0.8 秒后出第二行（金色）+ 副标签。
- 证据模块按口播句子**逐块出现**，数字有滚动、进度条有生长、连接线有描线。
- 最后一句口播时，金色结论句 + 下划线出现。
- 切段：旧内容淡出，新内容从标题重新搭起；画框、背景、账号区始终不动。

## 可换的皮肤（同一结构，不同视觉）

黑金（样片原版）· 深海蓝 · 中国红 · 米白纸感。背景大字由 AI 按主题挑选（例如“学”“考”“分”）。

## 刻意不照搬的地方

- 不抄账号名、头像、K 字背景和文案内容；背景字、配色、模块组合都是参数。
- 样片 4 分半，我们按客户选择的 1 / 2 / 3 分钟控制段落数。
