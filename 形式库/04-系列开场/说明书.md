# 形式 04：系列开场

## 一句话灵魂

**给一个“追下去的理由”做钩子，几十秒内快速交代：这个系列讲什么/拍什么、我凭什么讲、什么节奏更新、追下去能得到什么，现在就关注。**

它是一个系列 / 连载的**第一集（开场片或先导片）**，核心目的是涨粉、立人设、让观众收藏追更。

## 适合谁（不限于课程）

| 客户 | 用来做什么 |
|---|---|
| 门店老板 / 手艺人 | “装修避坑 7 集”“开店这三年全拍给你看” |
| 教培老师 / 机构 | “每天一道压轴题”“每晚 10 分钟背单词” |
| 律师 / 医生 / 顾问 | “每天一个法律常识”“体检报告怎么看”系列 |
| 健身 / 美业 / 餐饮 | “减脂 30 天全过程”“后厨日常连载” |
| 博主 / 带货 | 案例合集、测评连载、每周复盘、挑战打卡 |

关键：**按客户自己的身份和内容写**，不要默认“老师 / 学员 / 讲义 / 错题本 / 睡前看一集”。

## 画面结构（竖屏 1080×1920）

```
┌───────────────────────────┐
│ (头像) 账号名               │
│        #话题 #话题           │
│ 装修避坑7集（绿青渐变大字）   │  ← 系列名，全片固定
│ 第一次装修少踩坑（白字）      │  ← 追更理由 / 承诺
│ ┌───────────────────────┐ │
│ │   深色网格“屏幕” 16:9    │ │  ← 每句口播换一个画面，节奏快
│ └───────────────────────┘ │
│        一行字幕             │
└───────────────────────────┘
```

## 屏幕里的画面（30 种，AI 按这一段在讲什么挑）

常用：type 打字钩子、icons 图标筛选观众、avatar 人设贴纸、calendar 更新节奏、episodes 连载目录、checklist 追完能得到什么、vs 以前 vs 现在、chat 常被问的问题、follow 关注引导、big 收尾钩子。

其它可用：tree 路线、cards 清单、countdown 计划天数、quote 金句、ask 提问、progress 进度、quest 闯关、levelup 升级、lockscreen 更新提醒、grid4 四宫格、gift 福利、neon 口号、pledge 承诺、timeline 时间线、quiz 小测、notebook 要点、top3、spotlight、faq。

“睡前 / 学习”类画面（bedtime、notebook、episodes 等）只在客户的内容确实是那种类型时才用，否则用更通用的画面。

## 节奏

一段一句，2–4 秒；全片 30–45 秒。默认背景音乐：燃炸电音。

## 刻意不照搬的地方

- 不使用对标样片的博主形象、账号名、App 图标（品牌 Logo 有版权，用表情图标代替）。
- 钩子不固定成“坚持一个月领先 90%”，换着写：拆成 N 集讲透 / 这一路全拍下来 / 看完你就知道 / 只讲这一次。
- 更新节奏按客户实际情况写（每天 / 每周 / 每周三更 / 连载 N 集 / 不定期）；客户没说就写“持续更新”。
- 文案由 AI 按客户的行业和人设重写，客户没给的数字一律不编。
