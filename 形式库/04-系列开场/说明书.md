# 形式 04：系列开场

> 对标样片：`如果你能坚持每晚睡前_20261112171339.mp4`、`如果你能坚持每晚睡前_20261112171730.mp4`（竖屏 720×1280，约 35–40 秒）

## 一句话灵魂

**用一个“每晚睡前看一集，一个月后领先 90% 的人”的承诺做钩子，几十秒内快速交代：这个系列讲什么、我是谁、怎么带你学、资料都备好了，现在就关注。**

它是一个系列 / 专栏的**第一集（开场片）**，核心目的是涨粉和立人设。

## 适合谁

| 客户 | 用来做什么 |
|---|---|
| 老师 / 个人 IP | 系列课开篇（“每天一道压轴题”“每晚 10 分钟背单词”） |
| 教培机构 | 免费专栏引流、打造名师人设 |
| 知识博主 | 专栏开篇、涨粉 |

## 画面结构（竖屏 1080×1920）

```
┌───────────────────────────┐
│ (头像) 账号名               │
│        #话题 #话题           │
│ 每晚睡前看一集（绿青渐变大字） │  ← 系列钩子，全片固定
│ 你的数学就会很牛（白字）      │
│ ┌───────────────────────┐ │
│ │   深色网格“屏幕” 16:9    │ │  ← 每句口播换一个画面，节奏快
│ └───────────────────────┘ │
│        一行字幕             │
└───────────────────────────┘
```

## 屏幕里的 7 种画面

| 类型 | 效果 | 对应样片 |
|---|---|---|
| type | 逐行打字，关键词标黄，每行配英文小字 | “如果你能坚持每晚睡前看一集” |
| icons | 标题 + 一排图标依次弹出 + 一句大字 | “不感兴趣的人大概率刷不到我” |
| avatar | 人设贴纸（照片抠图加白边）+ 弯曲黄色大字 + 信息卡 | “最宠粉的博主” |
| tree | 路线图：根节点下逐个长出分支 | “半年时间：安装 → 配置 → 落地” |
| big | 一句金句大字弹出 | “从 AI + 行业的角度” |
| cards | 一堆资料卡片铺满屏幕 | “学习笔记我都整理好了” |
| follow | 头像 + 对勾 + 点赞关注评论 | “现在关注，你就是原始股东” |

## 节奏

一段一句，2–4 秒；全片 30–45 秒。默认背景音乐：燃炸电音。

## 刻意不照搬的地方

不使用样片的博主形象、账号名、App 图标（品牌 Logo 有版权，用表情图标代替），文案由 AI 按客户的科目和人设重写。
