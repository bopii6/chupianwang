# 形式 03：真人图文口播

> 对标样片：`新型半日营学业规划模_20261112135538.mp4`、`新型教培行业AI教育_20261112135735.mp4`（横屏 1280×720，约 40–60 秒）

## 一句话灵魂

**真人站在画面里“讲”，旁边的标题像打字一样蹦出来，标签、表格、贴纸跟着口播一个个弹出，底部中英双语字幕。**

样片里的真人其实是同一个人的几张**静态照片**（摊手、比心、握拳、抱电脑），每个镜头换一个姿势。靠“换姿势 + 弹出效果”制造节奏，并不需要真人录视频。

## 适合谁

| 客户 | 用来做什么 |
|---|---|
| 教培机构老板 / 校长 | 招生宣传、课程介绍、机构招商 |
| 老师 / 个人 IP | 行业观点、新模式解读，建立“懂行”的人设 |

关键词：**真人出镜的信任感 + 信息密度**。

## 我们的做法

- **真人**：客户上传 3–6 张自己的半身照，换不同手势。工具在浏览器里自动抠图（MediaPipe 人像分割，Apache-2.0 协议，可免费商用），照片只存在客户自己的电脑里，不上传。没上传照片时用代码画的卡通讲师。
- **画幅**：竖屏 1080×1920。上方是常驻口号，中间是图文区和真人，下方是中英双语字幕。
- **人物大小自动适配**：先算出这一镜图文占到多低，再决定人物放多大，保证不挡脸。

## 画面元素（AI 按内容挑选）

| 类型 | 效果 |
|---|---|
| title | 红色大标题打字蹦出 + 副标题 |
| tags | 粉色标签逐个弹出 + 黄色重点条 |
| table | 小表格逐行滑入（方案、报告、对比） |
| stat | 大数字滚动 + 黄色马克笔底 |
| emoji | 表情贴纸弹出、轻轻浮动，配短标签 |
| list | 打勾清单逐条出现 |

## 结构

钩子（机会 / 痛点）→ 是什么 → 怎么做 → 好处 → 行动号召（评论区关键词，例如“留言 888”“扣 1”）。

## 皮肤

白底红字（默认）· 暖黄纸感 · 深蓝商务。默认背景音乐：活力流行。

## 刻意不照搬的地方

不用样片里的人物形象、口号和文案；英文字幕由 AI 翻译，每句对应。
