# 视频号转存（自建活会话）运维说明

2026-11-28 起，线上"粘贴视频号链接 → 拆解"不再只依赖外部托管服务，
改为 **自建通道优先、托管兜底**，两边都挂才会让客户看到报错。

## 一、请求是怎么走的

```
客户粘链接
  └─ 0. 结果缓存（7 天，同一链接全站复用）        lib/copylib.js  sphCacheGet
  └─ 1. 本机通道（只在本机版生效）                  lib/sphlocal.js
  └─ 2. 自建服务 http://127.0.0.1:8001            /opt/sph/dl/cloud/app.py
  └─ 3. 托管兜底 http://8.140.220.104:8000        （外部，我们没有 shell）
```

每台服务提交前会先问一句 `/api/health`：自建那台如果元宝 Cookie 掉了会秒回
`ready:false`，线上直接跳过它走兜底，不会让客户干等 20 秒。
接口返回里的 `via` 字段就是这次走的哪条路：`cache` / `local` / `self` / `hosted`。

## 二、服务器上有什么（115.190.113.128，/opt/sph）

| 东西 | 位置 / 命令 | 说明 |
|---|---|---|
| 解析服务 | `systemctl status sph-wxcd` | Linux 版 wx_video_download，听 127.0.0.1:2022 |
| 转存 Web | `systemctl status sph-web` | uvicorn，听 127.0.0.1:8001，带访问码（/opt/sph/web.env） |
| 巡检 + 自动续 | `systemctl status sph-health.timer` | 每 10 分钟；结果写 `/opt/sph/health.json` |
| 元宝 Cookie | `/opt/sph/bin/config.yaml` 的 `sphCookie` | **Linux 版是驼峰**，写成小写会一直"缺少 Cookie" |
| Cookie 池 | `/opt/sph/cookies.json` | 每次续期往里加一条，保留 5 条 |
| 浏览器配置 | `/opt/sph/browser` | 扫码后的登录态存在这里，几周有效 |

脚本：

- `refresh_cookie.py`：Xvfb + chromium 跑一遍元宝，取 Cookie（缺 `hy_token` 会拒绝写入），写配置、重启 wxcd、自检
- `login_qr.py`：需要人工扫码时用。二维码每 10 秒刷新到 `/opt/sph/qr.png`，扫完自动写 Cookie
- `health.py`：巡检。wxcd 挂了拉起；通道不可用就自动续期；续不上就写 `needs_scan` 并告警
- `e2e.py`：跑一条真实链接，打印状态/耗时/大小

## 三、日常

**正常情况下什么都不用做。** 元宝登录态一般能撑几周，巡检会自己续。

要确认现在好不好使：

```bash
curl -s http://127.0.0.1:8001/api/health      # ready:true 就是好的
/usr/bin/python3.11 /opt/sph/e2e.py          # 跑一条真实链接
```

**需要重新扫码时**（`/opt/sph/needs_scan` 出现，或 health.json 里 sph:false）：

```bash
rm -f /opt/sph/login.lock
/usr/bin/python3.11 /opt/sph/login_qr.py &   # 二维码刷到 /opt/sph/qr.png
# 把 qr.png 发给负责人，用微信扫，1 分钟内有效
```

## 四、告警

`/etc/systemd/system/sph-health.service` 里没有写死 webhook，用环境变量传：

```ini
Environment=SPH_ALERT_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx
```

配了之后，只有"需要人工扫码"这种自己解决不了的情况才发一条，不刷屏。

## 五、坑（都踩过）

| 现象 | 原因 |
|---|---|
| 通道一直"缺少 yuanbao.tencent.com Cookie" | Linux 版键名是 `sphCookie` 驼峰；或 Cookie 被折行了 |
| 取到的 Cookie 写进去后报"此内容暂时无法播放" | 缺 `hy_token`。无界面浏览器/裸 HTTP 拿不到，必须真浏览器 |
| 浏览器起不来 | Xvfb 没起。脚本会自动起 `:99` |
| 巡检把登录窗口杀了 | 已加 `/opt/sph/login.lock` 互斥，登录期间巡检跳过 |
| `pnpm`/`npm` 装轮子很慢 | 这台机器在国内，GitHub 直连会超时，二进制从本地 scp 上去更快 |
